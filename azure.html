Azure学習プラン — cultivate

目的：AIを用いた実務プロダクトを設計・実装できるスキル獲得
期間: 2026‑07〜2026‑12 ホームに戻る
何のための学習か

これまでのクリエイティブ／UX／マーケティング経験に、Azure + OpenAI を組み合わせた実務スキルを掛け合わせる。最終アウトプットは「動く成果物（Azure上で動作するプロトタイプ）」とその解説資料。

公開時の注意：個人的な会議名や他人の個人情報は非公開にしてください。具体日程は「フェーズ」や「月単位の目安」にすると見やすいです。

目標（ゴール）
  • AI-900（基礎）合格
  • AI-102（実装）合格を目標に学習・模擬試験
  • Azure + OpenAI を使ったポートフォリオプロダクトを1つ公開
おすすめ学習フェーズ（短め）
Phase 1: 基礎（2〜3週間） — AI/Cloud 基礎、AI-900
Phase 2: 応用（6〜10週） — AI-102 入門、設計演習
Phase 3: 実装（4〜8週） — プロトタイプ開発
Phase 4: ブラッシュアップ（2〜4週） — 公開 & ドキュメント
週次サンプル（フルタイム／副業別に調整）
曜日学習内容（例）
月概念学習（Azure AI サービス、認証、料金） 1.5h
水Hands-on（Azure Portal, OpenAI API, サンプル実装）2h
金試験対策（模擬問題・テクニカルノート整理）1h
土プロトタイプ作業（設計→実装）3〜4h

※勤務時間に合わせて「合計学習時間／週」を目標化（例：6〜10時間/週）すると継続しやすいです。

アイデア（ポートフォリオ候補）
  • 業務ログから自動で要約／改善提案をするダッシュボード（Azure Functions + OpenAI）
  • 対話型FAQチャット（Blob Storageに保存したナレッジを参照）
  • 画像解析＋キャプション生成でUX改善提案ツール
チェックポイント（マイルストーン）
  • Phase1完了：AI-900合格 or 概念整理ノート完成
  • Phase2中間：プロトタイプ最低限のMVPを設計
  • Phase3完了：Azure上で動くデモを公開
推奨リソース
  • Microsoft Learn (Azure)
  • AI-900 学習パス
  • AI-102 学習パス
  • Cognitive Services ドキュメント
  • 実戦：公式 Quickstart と GitHub サンプルをクローンして動かす
成果の見せ方（採用向け）
  1. デモページ（公開URL） + 短い動画（60–120秒）
  2. README：目的、構成、セットアップ手順、試したこと
  3. 技術要約：アーキテクチャ図、課題と解決策、使ったAzureサービス
